# H-Beauty Neural Makeup Studio — isolated research preview

**Live neural app:** https://h-beauty-neural-makeup-studio-p8au6h.v2.appdeploy.ai/

This is a real, hosted neural image-editing workflow using Gemini's generative image model via the AppDeploy AI backend. Users supply their own face photo and an optional makeup reference or select a preset, consent to cloud processing, and receive an automatically generated makeup image. **No manual painting or hand-drawn region masks are involved.** The UI supports before-and-after comparison and export.

**Research limitation:** Photorealism, reference fidelity and identity preservation are not independently certified. The platform limits image input to 2 MP (max dimension 1600px) and output size to 1 MB. The app is not offline. Personal photos are sent to the hosted model only with explicit consent. Do not mistake this app for the unimported V14 research package, which has no real-photo-trained neural checkpoint.

The original production H-Beauty site is not modified.
