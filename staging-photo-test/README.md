# H-Beauty Makeup Photo Test Studio

This subfolder holds the complete source snapshot of the independently deployed [H-Beauty Makeup Photo Test Studio](https://h-beauty-makeup-photo-test-studio-phim6t.v2.appdeploy.ai/).

**Not the full V14 neural application.** This is a manual browser-only image review companion: three separately painted masks (lips/eyes/cheeks), configurable colors, local image processing, before/after comparison, protected-pixel integrity check, and native-resolution PNG export. The sample portrait is explicitly schematic. Photos are not transmitted to a server.

Run locally: `npm install`, `npm run dev` from this subdirectory. The V14 research ZIP has not been imported into the root app, and this preview does not demonstrate a trained photorealistic model.
